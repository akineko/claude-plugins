# fulfill — 合意の履行

固定した合意を唯一の仕様源として実装する。合意にないことは足さず、合意と矛盾する発見は隠さず、裁量で決めたことは記録する。

## 手順 1: 合意の取得

仕様源を次の優先順で特定する:

1. 引数で指定された合意ファイル
2. この会話の readback で固定したインライン合意または作成した合意ファイル
3. `docs/agreements/` の `status: active` なファイル（複数あればどれの続きかをユーザーに確認）
4. どれもない場合: readback スキルの軽量〜標準の手順で解釈宣言（必要なら合意ファイル作成）を先に行ってから戻る。**合意なしで実装に入らない**。

合意ファイルの場合は「現在地」を読み、前回からの続きであれば再開点から始める。

## 手順 2: タスク分解

完了条件を作業順のタスクに分解する。分解の基準:

- 各タスクは「どの完了条件に効くか」を持つ（どの条件にも効かないタスクはスコープ外の疑い。合意に照らして落とす）
- 独立なタスクは並列化を検討する
- テストで動作を固定できるものは TDD（先にテストを書き、失敗を確認してから実装）

## 手順 3: 実装

**実装の主体**: 少数ファイルの変更はこの場で直接実装してよい。多ファイルの読解を要する実装や独立タスクの並列実行には aligned-implementer エージェントを使う（メインの文脈を実装詳細で埋めないため）。

aligned-implementer に渡すもの:
- 合意ファイルのパス（または合意の該当部分の全文）
- 担当タスクと、そのタスクが効く完了条件
- 逸脱プロトコル上の停止条件（下記 L2）に該当したら実装を中断して報告せよという指示

## 逸脱プロトコル（実装中の発見の扱い）

実装中に「合意した時の想定と違う事実」を見つけたら、影響レベルを判定して行動する。**この判定を暗黙にやらない**こと自体がこのスキルの目的。

| レベル | 定義 | 例 | 行動 |
|--------|------|-----|------|
| **L0 裁量** | 合意が定めていない実装詳細 | 内部関数の命名、テストケースの構成、エラーメッセージの文面 | 既存規約に従い自分で決める。**別の合理的選択肢があった判断だけ**決定台帳に記録（種別: 裁量） |
| **L1 前提の更新** | 合意の「前提」が事実と違ったが、やること・完了条件は変わらない | 使う想定だったユーティリティが存在しない→別手段で同じ結果を出せる | 自分で決めて続行。台帳に記録（種別: 前提更新）し、合意ファイルの「前提」を書き換え、**次にユーザーへ話すとき必ず言及する** |
| **L2 合意の変更** | やること・やらないこと・完了条件・作業量の見立てが変わる | 依存ライブラリが必要機能を持たない／バグ修正のつもりが設計問題だった／完了条件の1つが検証不能と判明 | **作業を止めて報告**。勝手に進めも諦めもしない |

L2 停止時の報告フォーマット:

1. **発見した事実**（証拠つき: 該当コード・実行結果）
2. **合意への影響**（どの項目がどう変わるか）
3. **選択肢**（2〜3個、それぞれの影響と作業量感）＋**推奨と理由**（AskUserQuestion が使えるなら選択肢として提示）
4. **作業ツリーの状態**（どこまで進めて止めたか、そのまま残しているか）

ユーザーの決定後、合意ファイルを更新（台帳に種別: 合意変更、確認: ✔）してから再開する。

## 手順 4: 記録と報告

- 決定台帳への記録は判断をした時点で行う（まとめて後で、はやらない。忘れる）。
- インライン合意（ファイルなし）の場合、台帳の代わりに判断を覚えておき、完了報告の「裁量判断」節で開示する。
- タスク完了ごとに、完了条件に対する現在位置を1行で報告する（長い沈黙は認識ズレの温床）。

## 手順 5: 完了へ

全タスクが終わったら Skill ツールで signoff を起動して完了検証に進む（軽量なインライン合意の場合も、最低限「完了条件ごとの検証結果＋裁量判断の開示」は行う）。**「できました」とだけ言って終わらない**。

## 規律

- 合意にない改善を実装に混ぜない（気づいたら完了報告で提案として分離する）。
- L2 に該当するか迷ったら L2 として扱う（止まりすぎのコストは数分、進みすぎのコストは信頼）。
- テストを弱めて完了条件を満たしたことにしない（テストが通らないのは L2 の可能性）。
- 決定台帳には「ユーザーに聞かれたら説明が要る判断」だけを書く。全判断の記録はノイズで、開示の価値を薄める。
